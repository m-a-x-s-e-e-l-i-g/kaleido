Kaleido turns one wedge of the scene into 4, 6 or 12 reflected segments, with rotation and a movable center. Compose in LiveView and shoot native Canon RAW using the normal shutter.

This is the first public release, following Max Seelig's successful physical-camera test of **0.1.0-rc4**. Version 0.1.0 preserves that implementation; the build checks that only version metadata and module documentation changed.

- **Target:** original Canon EOS M · Canon 2.0.2 · Magic Lantern dev 2025-06-20 / EOSM.202.
- **Workflow:** A+ · Auto ISO · Canon RAW · single-shot · native 1× LCD · Global Draw ON.
- **Install:** power OFF, copy `ML/MODULES/kaleido.mo`, disable other MAXmade effect modules, enable Kaleido and restart. Read the included instructions.
- **Included:** camera module, source, license, import audit, checksums and standalone browser playground. Three new camera screenshots join the README and website gallery.
- **Validation:** full native and sanitizer checks, exact-core import audit, source comparison with tested rc4, independent byte-identical module rebuild and reproducible ZIP verification. The camera report is author-supplied; no measured FPS or per-feature camera test matrix is claimed.

Download **KALEIDO-0.1.0-EOSM202.zip** below. Bursts, video, remote triggers and long exposures are outside the supported workflow.
